# Lyrica Studio v0.1.1

MVの歌詞テロップを自由に演出する、サーバー不要・ライブラリ不要の静的 Web アプリです。

## 主な操作

1. `index.html` をブラウザーで開く（または GitHub Pages で公開）。
2. **動画を読み込む** で自分の MP4/MOV などブラウザー対応形式を選ぶ。
3. **文字を追加** または **歌詞を一括追加**。一括追加は「1行 = 1レイヤー」。
4. プレビュー上の文字をドラッグして位置変更。右の設定欄で、字体、色、サイズ、回転、縁取り、影、透明度を指定。
5. 下のタイムラインで各文字のクリップを移動・左右端で長さ調節。
6. 右欄の「動きの種類」でスライド、フェード、回転、タイプライター、スクロールなどを選択。**「下から上へ流れ続ける」**を選択すると、表示開始時刻に画面下から入り、終了時刻までに上へ抜けます。逆の「上から下へ」も選べます。
   - スクロールの速度は **表示終了 − 表示開始** の時間で決まります。長くすればゆっくり、短くすれば速く動きます。スクロール中の横位置は X の設定で調整できます。
   - **「下から浮き上がる」**は定位置まで登場して止まる別の動きです。
7. 細かな動きは、再生時刻を移動して X/Y、回転、拡大率、透明度を設定し「キーフレームを追加/更新」。
8. **プロジェクト保存** で編集 JSON を保存。次回は **開く** で再読込し、元動画も再度選択。
9. **動画を書き出す** で動画と歌詞を録画合成後、**完成動画を保存** を選択。OS/ブラウザーにより MP4 または WebM。端末による音声トラックの制限に注意。

## GitHub Pages で使う（Netlify 不要）

1. GitHub に **新規リポジトリ** を作成（例 `lyrica-studio`）。
2. この ZIP を解凍し、中身のファイル（`index.html`, `app.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`）をリポジトリの一番上にアップロードして Commit。
3. リポジトリ **Settings → Pages → Build and deployment** で Source に **Deploy from a branch**、Branch に **main / (root)** を選択して Save。
4. Pages に表示された公開URLを Safari で開く。Safari の共有ボタン → **ホーム画面に追加** で独立アプリのように使える。
5. 最初にページを読み込んだ後は、アプリの構成ファイルだけキャッシュされ、オフラインでも起動できます。ただし iOS の容量管理やブラウザーのキャッシュ削除で消える場合があります。

GitHub Pages に公開するのはアプリの **ソースコードのみ** です。選択した動画はブラウザー上のメモリーで処理し、どこにもアップロードしません。プライベート動画を GitHub のリポジトリにアップしないでください。

## 書き出し・保存の重要な制限

- **ブラウザー版の初期実装**です。出力は HTMLCanvasElement.captureStream() + MediaRecorder 方式で **実時間** に録画します。数分の動画には数分かかります。端末がスリープすると失敗する場合があります。
- MP4 対応はブラウザー依存です。Safari では MP4 が選ばれる傾向ですが、Chrome/Firefox の多くは WebM です。ファイル拡張子は実際の出力形式に合わせます。
- **元動画の音声付き書き出しはベストエフォート**です。Web Audio による結合を試みますが、iOS Safari などの環境によって無音や録画失敗になる可能性があります。音声を含む MP4 の確実な出力が必要なら AVFoundation を使うネイティブ iPad/macOS 版が適します。
- アプリ自体はオフライン利用ができますが、元動画は再起動後に再度選択する必要があります。動画ファイルはローカルで保持されません。
- プロジェクト JSON には歌詞・色・タイミング・キーフレームが入り、**動画本体、音声、カスタムフォントのファイルは入りません**。
- カスタムフォントはアプリ起動中だけ有効です。プロジェクトを再読込する場合は再度フォントを読み込んでください。データ保存もされません。
- 解像度は長辺1920pxまで。フレームレートは概ね30fpsです。映像の圧縮はブラウザー・端末に依存します。
- 映像の正確なフレーム単位での書き出し、複数映像トラック、音源と歌詞の自動同期、音声波形表示、歌詞自動解析はこの版に含まれていません。
- 静的サイトであるため、公開されている Pages の URL を他者も開けます。**編集した内容やファイルが自動で他ユーザーに見えることはありません**。

## 検証状況

Chromium を使い、テスト用の音声付き MP4 を取り込み、歌詞レイヤーの編集、再生、映像と音声の合成、編集 JSON、Undo、一括歌詞追加まで自動操作確認済み。iPad 実機での書き出しは未検証です。

## v0.1.1 アップデート方法

すでに GitHub Pages で使用中なら、ZIP の **全ファイル**を既存のリポジトリのルートに上書きコミットしてください。
service worker のキャッシュ名を変更しているため、反映後はアプリを完全に閉じて再起動するか、Safari で再読み込みしてください（古いファイルが一時的に表示される場合はもう一度再読み込み）。
公開ページの「LYRICA STUDIO」の左上が `v0.1.1` なら更新済みです。
