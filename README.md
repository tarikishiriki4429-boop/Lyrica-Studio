# Lyrica Studio v0.2.0 — MV文字演出／TYPE LAB

個人制作の動画に、日本語・英語の歌詞やタイトルを配置して、字体、位置、サイズ、回転、表示タイミング、文字の質感を自由に調整するオフライン対応Webアプリです。GitHub Pagesで公開可能。サーバー処理・外部JavaScriptライブラリは使いません。

## v0.2.0 新機能 — TYPE LAB

**文字を選択 → 右側の「TYPE LAB」** で次の3種類を切り替えられます。

- **STANDARD**：通常表示。既存のフォントや描画は継続。
- **SHATTER**：ひび割れ、文字内部の欠損、表面の剥がれ、微細な剥離、ずれた破片を描画。調整項目は「欠け・ひびの強さ」「表面の剥がれ」「破片のズレ」「亀裂の細かさ」。
- **GRAPHITE**：濃淡、芯の粒子感、文字ごとの揺れ、重ね描きのラインを加工。調整項目は「鉛筆の濃淡」「芯のざらつき」「手書きの揺れ」「重ね描きの線」。

**文字の現れ方**：通常、左から書き現れる、1文字ずつ現れる、断続的に瞬く。

**文字の消え方**：通常、左から消される、破片のように散って消える。

- 「登場時間」「退場時間」で各演出の長さを指定。既存のスクロール／スライド／フェードと同時利用できます。
- 「傷や筆圧のパターンを作り直す」は、選択レイヤーごとの模様をランダムに変更します。その後の再生・書き出しでは模様を固定するため、映像がちらつくことはありません。
- Shatter/Graphiteは**独自制作のプロシージャルな文字質感描画**で、全漢字対応の独立したTTF/OTF書体を収録したものではありません。選んだOSフォント／カスタムフォントをベースに加工します。
- 「左から書き現れる」は文字列を順に露出する演出であり、漢字の実際の筆順を再現する機能ではありません。

## 基本の使い方

1. **動画を読み込む** からMP4/MOVなどブラウザーで再生可能な動画を選択。
2. **文字を追加** または **歌詞を一括追加** でレイヤーを配置。1行ずつ別レイヤーにできます。
3. プレビュー上の文字を指で動かし、右側で字体・色・サイズ・縁・影・角度・透明度を設定。
4. **TYPE LAB** で「SHATTER」「GRAPHITE」を選び、質感の4つのスライダーを調整。
5. 「文字の現れ方」「文字の消え方」を指定。下にある「登場時間」「退場時間」で演出の秒数を変更。
6. タイムラインのクリップを動かすと表示位置（時間）が変わり、左右端のハンドルで長さが変わります。
7. 「動きの種類」で **下から上へ流れ続ける** などを設定可能。文字の動きの速さは表示区間の長さで決まります。
8. 細かな位置や角度の変化はキーフレームを利用。
9. **プロジェクト保存** は編集内容をJSONで保存、**開く** で再編集。質感の設定も保存されます。
10. **動画を書き出す** で動画と文字を重ねて再録画し、完了したら **完成動画を保存** します。

## GitHub Pages で公開（Netlify 不要）

すでに作ったリポジトリ：
https://github.com/tarikishiriki4429-boop/Lyrica-Studio

1. このZIPを**解凍**する。ZIPをそのままアップロードしないでください。
2. 解凍した中の **全10ファイル**（`index.html`、`style.css`、`typefx.js`、`app.js`、`sw.js`、`manifest.webmanifest`、`icon-192.png`、`icon-512.png`、`README.md`、`LICENSE`）をリポジトリ直下へアップロード。古いファイルがある場合は上書きします。
3. **Commit changes** を押す。
4. GitHubの **Settings → Pages** で **Deploy from a branch**、**main / (root)** を選び保存。
5. 公開先の `https://tarikishiriki4429-boop.github.io/Lyrica-Studio/` をSafariで開く（実際の公開はPages設定とデプロイ完了が必要）。Safariの共有メニューからホーム画面に追加可能。
6. 左上に **v0.2.0** が表示されることを確認。以前の画面が残る場合はSafariでページを再読込。Safariの全サイトデータ削除は、保存していない編集内容に影響するため推奨しません。

**注意**：GitHubにアップロードするのはアプリのコードと画像アイコンだけ。個人制作動画・音源はアップロードせず、Safari内でユーザーがファイルを選択して読み込む構造です。

## 保存・動作上の制限

- このアプリは**静的Webアプリ**です。最初のオンライン読み込み後、アプリ構成ファイルをキャッシュしてオフラインでも開ける設計ですが、端末によるキャッシュ削除や容量制限の影響を受けます。
- 動画の加工・書き出しは Canvas `captureStream()` と `MediaRecorder` による実時間録画です。ブラウザー対応状況によってMP4またはWebM。iPad/Safariでの音声混合、保存動作、品質は端末での確認が必要です。
- 実時間のため、2分の動画の書き出しには概ね2分以上かかります。途中でアプリを閉じたり端末をスリープさせないでください。
- 最高解像度は長辺1920px、30fps前後。フレーム精密な出力、書き順解析、筆圧センサーからの生成、複数映像トラック、歌詞の音声自動同期は未搭載です。
- 元動画・追加フォントはアプリ再起動時に再度読み込む必要があります。プロジェクトJSONには動画や外部フォントのバイナリを含みません。
- 外部のフォントファイル（TTF、OTF、WOFF）を読み込めます。ただし著作権や各フォントの利用条件にご注意ください。
- GitHub Pagesはソースコードの公開ページですが、アプリで選択した動画・歌詞などの編集内容は自動的に他の利用者に見えることはありません。
